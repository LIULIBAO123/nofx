# 代码结构、策略参数与提示词梳理

## 一、代码结构概览

### 1.1 runCycle 主流程（trader/auto_trader.go）

| 步骤 | 说明 |
|------|------|
| 0 | 检查 trader 是否已停止 |
| 1 | 风控暂停检查（stopUntil） |
| 2 | 每日 PnL 重置 |
| **3** | **buildTradingContext()**：拉持仓、候选、行情（含 4h/1h 涨跌）、OI 等 |
| 4 | saveEquitySnapshot |
| 5a | **若无候选**：执行 **checkDynamicStopLossTakeProfit(nil)**（无 AI trend_view）→ 记录并 return |
| 5b | 有候选：调 **GetFullDecisionWithStrategy**（AI 决策） |
| 5c | 从 decisions 解析 **trend_view 按持仓** → 得到 trendViewByPosKey |
| 5d | **checkDynamicStopLossTakeProfit(trendViewByPosKey)**：按 trend_view 调节止损确认周期 |
| 6 | 排序决策（先平后开）→ 执行开仓/平仓（AI 仅开仓模式下不执行 AI 的 close） |

逻辑一致点：有候选时先拿 AI 的 trend_view 再跑 SL/TP，使「反转时少确认、趋势/震荡时多确认」生效；无候选时仍对持仓做 SL/TP，不依赖 AI。

### 1.2 行情与提示词数据流

- **fetchMarketDataWithStrategy**（kernel）：按策略 **SelectedTimeframes / PrimaryTimeframe / PrimaryCount** 拉 K 线；持仓必拉，候选受 **MaxCoinsInPrompt** 与 OI 过滤限制。
- **formatMarketData**（kernel）：对每个标写入 **4h 方向 / 1h 方向 / 1h 与 4h 是否同向**（由 PriceChange4h/1h 与阈值 0.15% 算出），并附一句「先定方向再主周期入场；多周期不一致时轻仓或提高置信度仍可开仓」。
- **BuildUserPrompt**：账户、约束、策略 SL/TP 说明、最近成交、统计、**当前持仓**（含 formatMarketData）、**候选币**（含 formatMarketData）、OI/NetFlow/Price 排行；若有持仓且 AI 仅开仓，要求对 hold 输出 **trend_view** 及「识别到反转时输出 reversing」说明。
- **BuildSystemPrompt**：Schema、角色、硬约束、仓位与盈亏比、决策流程（**先 4h/1h 定方向再主周期找入场**）、Output Format 与 **trend_view** 字段说明。

### 1.3 止损/止盈执行（checkDynamicStopLossTakeProfit）

- 对每个仓位：最小持仓过滤 → 锁利 breakeven → **止损**（初始固定 → 追踪 → ATR → 支撑/阻力 → 逆势早退）→ **止盈**（分层 → 回撤止盈 → 固定 → ATR → 阻力）。
- **trend_view 调节**：仅改**止损确认周期数**。`reversing` → requiredCycles-1（最少 1）；`trend_intact`/`choppy` → requiredCycles+1。不改变触发价格或止盈逻辑。

## 二、策略参数与预设建议

### 2.1 指标与 K 线（Indicators.Klines）

| 参数 | 推荐预设 | 说明 |
|------|----------|------|
| PrimaryTimeframe | **15m** | 与「先 4h/1h 定方向再 15m 找入场」一致；扫描间隔建议 5m 或 15m |
| SelectedTimeframes | **["15m","1h","4h"]** | 多周期共振与方向判断 |
| PrimaryCount | 30 | 主周期 K 线根数，兼顾 token 与上下文 |
| MaxCoinsInPrompt | 8（或 0 用默认 8） | 候选写入 prompt 上限 |
| EnableMultiTimeframe | true | 多周期数据 |

### 2.2 指标开关（与 4h/1h 方向及结构判断一致）

| 参数 | 推荐预设 | 说明 |
|------|----------|------|
| EnableEMA | true | 趋势/结构（如 EMA20） |
| EnableMACD | true | 动能 |
| EnableRSI | true | 超买超卖 |
| EnableATR | true | 止损/止盈倍数与波动 |
| EnableVolume / EnableOI / EnableFundingRate | true | 量、OI、资金费率 |

### 2.3 风控（RiskControl）

| 参数 | 推荐预设 | 说明 |
|------|----------|------|
| AIOnlyEntry | **true** | 平仓由策略 SL/TP 执行；AI 仅开仓 + 持仓 trend_view |
| MaxPositions | 3 | 同时持仓上限 |
| MinRiskRewardRatio | 3.0 | 执行前校验，低于则拒绝开仓 |
| MinConfidence | 70 | 开仓置信度建议，70 平衡机会与质量 |

### 2.4 动态止损（DynamicStopLoss）

| 参数 | 推荐预设 | 说明 |
|------|----------|------|
| Enabled | true | 启用动态止损 |
| MinHoldMinutes | 10 | 未满不参与 SL/TP，避免开仓即触发 |
| InitialStopPercent | 0 | 无固定初始止损，与前端一致 |
| TrailingEnabled | true | 追踪止损 |
| TrailingLevels | [2.5%/1.5%, 6%/2.5%] | L1/L2 激活与回撤 |
| ATR 倍数 | 1.5 / 2.5 | 高波动用 max |
| ConfirmCycles | 2 | 连续 2 周期满足才执行 |
| KlinesTimeframe | "15m" | 与主周期一致 |
| ATRToleranceEnabled | true | 高波动多 1 确认 |
| SupportResistanceEnabled | false | 默认关，按需开 |
| AdverseExitWhenNeverProfitATR | 0 | 默认关，按需设 1.0–1.2 |

### 2.5 动态止盈（DynamicTakeProfit）

| 参数 | 推荐预设 | 说明 |
|------|----------|------|
| Enabled | true | 启用动态止盈 |
| MinHoldMinutes | 10 | 与止损一致 |
| MinProfitPercentToAllowTP | nil | 不限制 |
| ScaledLevels | **2.5%/25%, 6%/25%, 10%/100%** | 三档依次 2.5%/6%/10% 满足震荡锁利 |
| ATR 倍数 | 2.5 / 4.0 | 高波动用 max |
| LockProfitPercent | 2.5 | 达此后回撤到成本按 breakeven 止损 |
| TrailingTPEnabled | false | 默认关，按需开 |

## 三、提示词一致性

### 3.1 已对齐

- **入场顺序**：System 与 User 均要求「先 4h/1h 定方向，再主周期找入场」；多周期不一致时「轻仓或提高置信度，仍可开仓」。
- **趋势区分**：持仓时对 hold 必须输出 trend_view；识别到结构反转/趋势破坏时输出 reversing，策略减少确认、更快止损。
- **formatMarketData**：显式 4h/1h 方向与 1h 与 4h 同向，并附一句说明。

### 3.2 需与预设一致

- **CustomPrompt / TradingFrequency** 中若写「分批止盈：4%/7%/10%」应改为当前预设 **2.5%/6%/10%**，避免与策略实际档位不符。
- **EntryStandards** 中 MinConfidence 若写 60，与预设 70 不一致时以**系统 BuildSystemPrompt 中的硬约束为准**（从 RiskControl 读取）；PromptSections 中的数字建议与预设一致或改为「≥ 策略配置的 MinConfidence」。

---

## 四、预设落点（GetDefaultStrategyConfig）

- **Indicators.Klines**：PrimaryTimeframe **15m**，SelectedTimeframes **["15m","1h","4h"]**，PrimaryCount 30，MaxCoinsInPrompt 0（使用 kernel 默认 8）。
- **Indicators**：EnableEMA / EnableMACD / EnableRSI / EnableATR 设为 **true**，便于方向与结构判断。
- **RiskControl**：**AIOnlyEntry true**；MinConfidence **70**；MinRiskRewardRatio 3.0；DynamicStopLoss / DynamicTakeProfit 按上表（含 2.5% 第一档、KlinesTimeframe 15m、InitialStopPercent 0）。
- **PromptSections / CustomPrompt**：分批止盈描述改为 2.5%/6%/10%；EntryStandards 中置信度与 MinConfidence 一致（70）。

以上保证：代码结构、策略参数与提示词三者一致，且预设符合「方向优先、震荡可开仓、止盈止损到位、AI+策略结合」的理念。
