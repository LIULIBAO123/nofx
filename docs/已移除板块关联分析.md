# 已移除板块（数据、策略市场、竞技场、常见问题）关联分析

## 结论摘要

- **数据**、**策略市场**、**竞技场**、**常见问题** 四个板块与保留的 **配置、看板、实盘模拟、策略、排行榜、Backtest** 无业务依赖关系。
- 仅存在入口与路由层面的引用；移除后保留板块功能不受影响。

## 逐项分析

### 1. 数据（/data, DataPage）

| 引用位置 | 说明 |
|----------|------|
| App.tsx | 路由 `/data`、currentPage === 'data' 时渲染 `<DataPage />`；pathMap / getInitialPage |
| LandingPage | pathMap 中 'data': '/data'（首页顶栏点击跳转） |
| HeaderBar | 已从导航移除，仅 Page 类型仍含 'data' |

**其余板块是否依赖：** 无。配置/看板/策略/排行榜/Backtest 均不链接到数据页，也不引用 DataPage。

---

### 2. 策略市场（/strategy-market, StrategyMarketPage）

| 引用位置 | 说明 |
|----------|------|
| App.tsx | 路由与 currentPage === 'strategy-market' 渲染 `<StrategyMarketPage />`；pathMap / getInitialPage |
| LandingPage | pathMap 中 'strategy-market': '/strategy-market' |
| **AgentGrid.tsx** | 首页「策略市场」CTA 按钮：已登录用户点击跳转 `window.location.href = '/strategy-market'` |

**其余板块是否依赖：** 无。仅首页 AgentGrid 有一处跳转至策略市场；移除后改为跳转 **策略**（/strategy）或 **排行榜**（/competition）。

---

### 3. 竞技场（/debate, DebateArenaPage）

| 引用位置 | 说明 |
|----------|------|
| App.tsx | currentPage === 'debate' 渲染 `<DebateArenaPage />`；pathMap / getInitialPage；Footer 在 debate 页隐藏 |
| LandingPage | pathMap 中 'debate': '/debate' |
| HeaderBar | 已从导航移除 |
| api.ts | 辩论相关接口 `/api/debates` 等仅辩论页使用 |

**其余板块是否依赖：** 无。后端辩论 API 仅竞技场页使用；移除前端后接口可保留不动。

---

### 4. 常见问题（/faq, FAQPage）

| 引用位置 | 说明 |
|----------|------|
| App.tsx | 路由 `/faq` 单独分支渲染 `<FAQPage />`（无需登录）；pathMap / getInitialPage |
| LandingPage | pathMap 中 'faq': '/faq' |
| FAQPage | 使用 FAQLayout → FAQSidebar / FAQContent，数据来自 data/faqData.ts |
| ExchangeConfigModal | 仅外链「Binance 如何创建 API」到 binance.com/.../faq/...，与本站 FAQ 无关 |

**其余板块是否依赖：** 无。FAQ 为独立页，无其余板块引用。

## 保留板块与四项的关系

- **配置（/traders）**：不引用数据/策略市场/竞技场/FAQ。
- **看板（/dashboard）**：不引用上述四项。
- **实盘模拟（/simulation）**：不引用上述四项。
- **策略（/strategy）**：不引用上述四项。
- **排行榜（/competition）**：不引用上述四项。
- **Backtest（/backtest）**：不引用上述四项。

## 实施时修改点

1. **App.tsx**：删除四页的 import 与路由分支；对 `/data`、`/strategy-market`、`/debate`、`/faq` 做重定向至 `/`；pathMap / getInitialPage 去掉四项；Page 类型去掉四项。
2. **HeaderBar.tsx**：Page 类型去掉 'data'|'strategy-market'|'debate'|'faq'（与 App 一致）。
3. **LandingPage.tsx**：pathMap 去掉 'data'、'strategy-market'、'debate'、'faq'。
4. **AgentGrid.tsx**：已登录用户 CTA 跳转由 `/strategy-market` 改为 `/strategy`（或 `/competition`）。
5. **页面文件**：DataPage.tsx、StrategyMarketPage.tsx、DebateArenaPage.tsx、FAQPage.tsx 及 components/faq/、data/faqData.ts 可保留不删（仅不再挂路由），便于日后恢复或复用。
