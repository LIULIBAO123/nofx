# 最新数据源与提示词 / 代码参数 / 逻辑 / 数据传递 AI 结构

本文在「全部应用」补强/替代/新增后，梳理**最新数据源**，以及**提示词、代码参数、代码逻辑、传递给 AI 的数据结构**是否已更新及更新要点。

---

## 一、最新数据源一览

### 1.1 按来源分类

| 数据源 | 提供的数据 | 使用板块 | 备注 |
|--------|------------|----------|------|
| **行情（market / 交易所 K 线）** | K 线、价格、4h/1h 涨跌、EMA、MACD、RSI、量、单标的 OI、FundingRate | 过滤、方向池、AI 实时、AI 预测、SL/TP（ATR） | 主数据源，未替代 |
| **nofxos** | OI 排行、净流入排行、涨跌榜 | 过滤、方向池、AI 实时、AI 预测 | 未替代 |
| **Binance** | 多空比、资金费率、Taker、8h 均值、Basis（或自算） | 方向池、AI 实时、AI 预测 | 启用 Coinglass 时 BTC/ETH 等可由 Coinglass 多所覆盖 |
| **Coinglass（KeyStore REST）** | OI 汇总、多所资金费率、多所多空、强平聚合、恐惧贪婪、BTC 占比、山寨季、ETF 流、**鲸鱼指数/CGDI/CDRI**、**强平热力图关键价位** | 过滤、方向池、AI 实时、AI 预测 | 已接入：鲸鱼/CGDI/CDRI 写 Context 与 Prompt，方向池 CGDI/鲸鱼加成；强平热力图关键价位写 Context 与 Prompt |
| **Coinglass WSS（可选）** | 融资率、清算、未平仓、价格 频道最新一条 | AI 实时、AI 预测（通过 CoinglassWSSSnapshot） | 配置 EnableCoinglassWSS 后懒加载连接并写入 Context |
| **CoinAnk / 币安 WS** | 强平聚合（1h/4h/24h 多空 USD） | 方向池、AI 实时、AI 预测 | 与 Coinglass 强平可并存 |
| **交易所 / 交易层** | 账户、持仓、订单、成交 | AI 实时、AI 预测、止盈止损调整 | 不变 |
| **策略配置与缓存** | Bounds、上周期 regime/scenario、本周期市场摘要 | 止盈止损调整、5 种场景 | 新增：本周期摘要 BuildCurrentCycleSummaryForSLTP |

### 1.2 数据流简图（应用后）

```
行情 + nofxos + Binance + Coinglass(REST) + [Coinglass WSS]
    → Context（含 CoinglassOISummaries, CoinglassFundingMap, CoinglassLongShortMap, CoinglassLiquidation,
               FearGreed*, AltcoinSeason*, ETFFlow*, WhaleIndex/CGDI/CDRI, LiquidationKeyLevels, CoinglassWSSSnapshot）
    → 过滤机制（Layer1 funding_ok 增加 Coinglass 多所费率校验）
    → 方向池（多标的多所多空写入 BinanceLongShortMap/CoinglassLongShortMap）
    → BuildUserPrompt（formatDataStrengtheningForAI 含上述 + WSS 提示）
    → AI 预测
    → 三条件共振 + 开仓

主周期 / 系统周期 缓存 lastMarketSummaryForSLTP
    → 止盈止损专用分析（BuildSLTPOnlyPrompts 增加 currentCycleSummary）
    → 5 种场景（choppy_hold / trend_ride / lock_profit / trend_weakening / high_vol_hold）
```

## 二、提示词（Prompt）更新

### 2.1 主流程 User Prompt（BuildUserPrompt / formatDataStrengtheningForAI）

| 更新点 | 说明 |
|--------|------|
| **数据补强区块** | 已包含：Coinglass OI、多所资金费率、多所多空、Coinglass 强平、恐惧贪婪、山寨季、ETF 资金流；**鲸鱼指数/CGDI/CDRI** 一行；**强平热力图关键价位** 一行；当 `ctx.CoinglassWSSSnapshot` 非空时追加「Coinglass WSS 实时」。 |

| 更新点 | 说明 |
|--------|------|

## 三、代码参数（配置）更新

### 3.1 策略 / 指标配置（store.IndicatorConfig）

| 参数 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `EnableCoinglassData` | bool | false | 是否启用 Coinglass 数据（REST） |
| `CoinglassProxyURL` | string | KeyStore v4 默认 | KeyStore 代理 Base URL |
| `CoinglassAPIKey` | string | "" | KeyStore API Key |
| **`EnableCoinglassWSS`** | **bool** | **false** | **是否启用 Coinglass WSS 实时推送（融资率/清算/OI/价格），补强 AI** |

### 3.2 前端（IndicatorEditor / types）

| 更新点 | 说明 |
|--------|------|
| **types.IndicatorConfig** | 新增 `enable_coinglass_wss?: boolean`。 |
| **IndicatorEditor** | 在 Coinglass 区块内新增「启用 WSS 实时（融资率/清算/OI/价格）补强 AI」勾选项，绑定 `config.enable_coinglass_wss`。 |

### 3.3 其他代码参数

- **Pipeline Layer1**：无新增配置项；`funding_ok` 在存在 `ctx.CoinglassFundingMap` 时自动做多所费率补强。
- **方向池**：多所多空拉取标的 = BTC/ETH + 候选列表最多 8 个（由 `FillCoinglassData` 内逻辑固定），无需新参数。

## 四、代码逻辑更新

### 4.1 过滤机制（kernel/pipeline.go）

| 逻辑 | 更新内容 |
|------|----------|
| **checkLayer1Item("funding_ok")** | 在原有 `md.FundingRate` 区间校验基础上，若 `ctx.CoinglassFundingMap` 存在且当前标的对应 Coinglass 币种（BTC/ETH），则**同时**要求 Coinglass 多所费率在 [-0.01, 0.01] 内，否则不通过。 |
| **symbolToCoinglass** | 新增：将交易对转为 Coinglass 币种（如 BTCUSDT→BTC），供 funding_ok 与后续扩展使用。 |

### 4.2 方向池与 Coinglass（kernel/engine.go）

| 逻辑 | 更新内容 |
|------|----------|
| **FillCoinglassData 多所多空** | 多空比拉取标的由固定 BTC/ETH 扩展为：**BTC、ETH + ctx.CandidateCoins 中最多 8 个不重复 base 币种**；写入 `CoinglassLongShortMap` 与 `BinanceLongShortMap` 时，key 同时使用 **BTCUSDT/ETHUSDT** 与 **BTC/ETH**，以便 pipeline/方向池按交易对查找。 |
| **symbolToCoinglassBase** | 新增：从交易对取 base 符号（如 BTCUSDT→BTC），供多空拉取列表使用。 |

### 4.3 止盈止损专用分析（kernel/engine.go + trader）

| 逻辑 | 更新内容 |
|------|----------|
| **BuildSLTPOnlyPrompts** | 新增参数 `currentCycleSummary string`，并在 userPrompt 中追加本周期市场摘要（若非空）。 |
| **RunSLTPOnlyAnalysis** | 增加参数 `currentCycleSummary`，并传入 BuildSLTPOnlyPrompts。 |
| **BuildCurrentCycleSummaryForSLTP** | 新增：从 Context 生成一句摘要（BTC 1h/4h、Fear&Greed、AltcoinSeason、强平 1h），供 SL/TP 与 5 种场景使用。 |
| **trader.runCycle / runSystemCycle** | 在构建 Context 后，调用 `kernel.BuildCurrentCycleSummaryForSLTP(ctx)` 并写入 `at.lastMarketSummaryForSLTP`。 |
| **trader.runSLTPAnalysisCycle** | 调用 `RunSLTPOnlyAnalysis(..., summary)` 时传入 `at.lastMarketSummaryForSLTP`。 |

### 4.4 Coinglass WSS（trader + kernel）

| 逻辑 | 更新内容 |
|------|----------|
| **buildTradingContext** | 当 `EnableCoinglassData && EnableCoinglassWSS && CoinglassAPIKey != ""` 时：懒加载 `coinglass.WSClient`，Connect 成功后 `go Run()`；若客户端非空，则对各频道（funding-rate, liquidation, open-interest, price）调用 `GetLatest`，写入 `ctx.CoinglassWSSSnapshot`。 |
| **AutoTrader** | 新增字段 `coinglassWSClient`、`coinglassWSClientMu`，用于持有与懒加载 WSS 客户端。 |
| **formatDataStrengtheningForAI** | 当 `len(ctx.CoinglassWSSSnapshot) > 0` 时，追加一行提示「Coinglass WSS 实时」已接入。 |

## 五、传递给 AI 的数据结构（Context）更新

### 5.1 Context 新增字段（kernel.Context）

| 字段 | 类型 | 说明 |
|------|------|------|
| **CoinglassWSSSnapshot** | `map[string]string` | Coinglass WSS 各频道最新一条消息；可选。 |
| **CoinglassWhaleIndex** | `float64` | 鲸鱼指数最新值（Binance BTC 1h），方向池与 AI 补强。 |
| **CoinglassCGDI** | `float64` | CGDI（多空扩散）最新值，方向池加成与 AI。 |
| **CoinglassCDRI** | `float64` | CDRI（衍生品风险）最新值，AI 参考。 |
| **CoinglassLiquidationKeyLevels** | `string` | 强平热力图关键价位一句摘要（如 BTC 24h sample levels），补强 scenario / key_levels。 |

其余 Coinglass 相关字段（如 CoinglassOISummaries、CoinglassFundingMap、CoinglassLongShortMap、CoinglassLiquidation、FearGreed*、AltcoinSeason*、ETFFlow*）此前已存在。

### 5.2 写入 Prompt 的映射（与 AI 的接口）

| Context 数据 | 写入位置 | 说明 |
|--------------|----------|------|
| 账户、持仓、候选、方向池、行情、币安衍生 | BuildUserPrompt 各区块 | 不变 |
| 数据补强（资金费率 8h、Basis、BTC 占比、强平、Coinglass OI/资金/多空/强平/恐惧贪婪/山寨季/ETF） | formatDataStrengtheningForAI | 已有 |
| **CoinglassWSSSnapshot** | **formatDataStrengtheningForAI** | **新增**：有数据时追加一行 WSS 实时提示 |
| 本周期市场摘要 | **不直接写入主 Prompt** | 仅写入 **止盈止损专用** userPrompt（currentCycleSummary） |

### 5.3 止盈止损专用分析输入（SLTPPositionInfo + 字符串）

| 输入 | 来源 | 说明 |
|------|------|------|
| positions | 持仓 + Bounds | 不变 |
| regime, scenario | 上周期 AI 缓存 | 不变 |
| **currentCycleSummary** | **BuildCurrentCycleSummaryForSLTP(ctx)**，由主周期/系统周期缓存 | **新增**：本周期 BTC 1h/4h、Fear&Greed、AltcoinSeason、强平 1h 等一句摘要 |
