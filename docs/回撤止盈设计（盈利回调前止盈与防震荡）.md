# 回撤止盈设计：盈利回调前止盈 + 防范震荡

## 一、目标

- **不在高挡位才止盈**：避免「必须涨到 5%/8% 才触发」导致涨不到就回落、锁不住利润。
- **在盈利回调前止盈**：一旦已有一定盈利，从峰值出现回撤时触发止盈，在利润被吃回去前锁定。
- **防范震荡**：不用固定小回撤%（如 1%）以免正常波动就触发；用 **ATR 比例** 或 **确认时长** 过滤毛刺。

## 二、与现有机制的关系

- **分层止盈（Scaled TP）**：按「价格达到某档位」触发，适合目标明确时分批了结；不改动。
- **追踪止损（Trailing Stop）**：在止损侧，已达盈利档后从**峰值**回撤固定%则**全平**；逻辑类似「回撤止盈」，但是全平且归在「止损」里。
- **本方案（回撤止盈）**：放在**止盈**模块，可选**部分平仓**；回撤条件可用 **ATR** 或确认时长，更抗震荡；与分层可并存（先检查分层，再检查回撤止盈）。

## 三、规则设计

### 3.1 激活条件

- 仅当**价格维度浮盈** ≥ **激活阈值 M%**（如 2% 或 3%）时才考虑回撤止盈。
- 即：多单 `(最高价 - 入场价)/入场价 * 100 >= M`，空单用最低价与入场价。

### 3.2 触发条件

- 从**峰值**（多单=入场后最高价，空单=入场后最低价）回撤达到 **R** 时触发。
- **R 的两种取法（防震荡）**：
  - **固定回撤%**：如 1.5%、2%，简单但震荡市易误触。
  - **ATR 比例**：`R = 0.5×ATR/当前价`（百分比），波动大时 R 自动变大，减少被震荡洗出。
- **推荐**：`R = max(固定回撤%, ATR比例%)`，既设下限又随波动放大。

### 3.3 确认（可选，进一步防震荡）

- 回撤条件需**持续满足**一段时间再执行：如 **N 分钟** 或 **N 根 K 线**（与止损侧的 ConfirmMinutes/ConfirmCycles 一致思路）。
- 不要求则单根 K 线达标即触发（更灵敏，适合趋势明显时）。

### 3.4 平仓方式

- 可配置为**部分平仓**（如 50%）或**全平**（100%）。
- 与分层止盈兼容：先算分层，再算回撤止盈；若先触发分层则先执行分层。

## 四、参数建议

| 参数 | 建议默认 | 说明 |
|------|----------|------|
| 启用 | 开 | 与分层/固定等并列，用户可关。 |
| 激活阈值 M% | 2 或 2.5 | 至少要有这么多盈利才考虑「回撤止盈」。 |
| 固定回撤% | 1.5 | 从峰值回撤超过该%即满足「回撤」条件之一。 |
| 回撤用 ATR 倍数 | 0.5 | 回撤幅度 ≥ 0.5×ATR/价格 时才认为有效，高波动时自动放宽。 |
| 取 R 的方式 | max(固定%, ATR%) | 固定%与 ATR% 取大，兼顾灵敏与防震荡。 |
| 确认时长（分钟） | 0 或 2 | 0=不确认；2=回撤持续 2 分钟再触发。 |
| 平仓比例 | 50 或 100 | 触发时平掉仓位的比例。 |

## 五、执行顺序

在 `CheckTakeProfit` 内建议顺序：

1. 分层止盈（先部分了结）
2. **回撤止盈**（本方案）
3. 固定止盈
4. ATR 止盈
5. 阻力止盈

这样：有分层时先按档位部分平；若未到档位但已有盈利且出现回撤，则用回撤止盈锁定。

## 六、小结

- **在盈利回调前止盈**：用「峰值 + 回撤」触发，不依赖涨到很高挡位。
- **防范震荡**：回撤幅度用 **max(固定%, ATR%)**，并可加**确认时长**，避免单根 K 线或小波动就触发。
- 与现有分层、固定、追踪止损并存；实现上在止盈模块新增「回撤止盈」类型即可。
