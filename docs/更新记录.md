## 历史记录

### 2026-03-02 策略/代码/提示词整体分析与提示词分层止盈统一
- **变更类型**：文档、kernel 提示词
- **主要内容**：（1）新增 `docs/策略与代码逻辑及提示词整体分析.md`，从配置来源、AI 仅开仓、动态止盈止损、分层止盈、平仓原因链、提示词与执行一致性做整体分析，结论为生效且合理。（2）提示词中分层止盈展示与执行统一：`formatStrategyDynamicSLTP` 改为「有档位即展示」分层止盈档位（与 take_profit 执行逻辑一致），避免配置有档位但 prompt 未显示。
- **涉及**：`kernel/engine.go`（formatStrategyDynamicSLTP）、`docs/策略与代码逻辑及提示词整体分析.md`（新建）

### 2026-03-02 分层止盈启用与优先级修正
- **变更类型**：后端（kernel + auto_trader）
- **主要内容**：（1）分层止盈未生效：当策略有 `scaled_levels` 但 `scaled_enabled` 为 nil（如旧策略或前端未勾选）时，现按「有档位即启用」处理，保证分层止盈会参与检查。（2）止盈检查顺序：先检查分层止盈再检查固定止盈，避免固定止盈与第一档同比例时直接全平、订单上看不到分层。（3）启动日志明确输出「分层止盈: 已启用/未启用」及 scaled_levels 数量，便于确认。
- **涉及**：`kernel/take_profit.go`、`trader/auto_trader.go`

### 2026-03-02 历史平仓「真正原因」推断（同期决策记录）
- **变更类型**：后端、前端、文档
- **主要内容**：当平仓记录为「交易所同步」（无具体原因）时，可根据同期决策记录推断并展示：在平仓时间前后时间窗内查找同标的、同方向的 close 决策，用其 Reasoning 作为推断原因；历史持仓接口返回 `inferred_close_reason` / `inferred_close_reason_detail`，前端在平仓方式/类型处显示「推断：系统止盈/止损」及详情。
- **涉及**：`store/decision.go`（GetRecordsInTimeRange、GetInferredCloseReason）、`api/server.go`（handlePositionHistory）、`web/src/types.ts`、`web/src/components/PositionHistory.tsx`、`docs/平仓类型显示说明.md`

### 2026-03-02 止损平仓原因未写入（symbol 兼容）
- **变更类型**：后端、文档
- **主要内容**：亏损单（应为系统止损）仍显示「交易所同步」：因 `SetPendingCloseReasonBySymbol` 仅用 normalized symbol（如 VVVUSDT）更新，若 DB 中持仓存为 VVV 则更新 0 行，OrderSync 处理平仓时读到的 CloseReason 为空。现改为与 `GetOpenPositionBySymbol` 一致，无行更新时再尝试用去掉 USDT 的 base symbol 更新，保证止损原因能写入并正确显示。
- **涉及**：`store/position.go`、`docs/平仓类型显示说明.md`

### 2026-03-02 分层止盈平仓原因写入（消除「无具体原因」）
- **变更类型**：后端、文档
- **主要内容**：策略为「仅系统止盈止损平仓」时，分层止盈此前只在「全额平仓」时写入 `close_reason`，导致最后一次部分平仓后同步得到的记录无原因。现改为每次执行止盈（含部分/分层）都调用 `SetPendingCloseReasonBySymbol`，保证完全平仓时仍能显示「系统」+「触发止盈」。
- **涉及**：`trader/auto_trader.go`（`executeTakeProfit`）、`docs/平仓类型显示说明.md`

### 2026-03-02 平仓类型展示与后端保留原因修正
- **变更类型**：前端、后端、文档
- **主要内容**：（1）前端：历史持仓的「平仓方式/平仓类型」中，`sync`/`unknown` 改为显示「交易所同步」及说明，仅 `manual` 显示「手动」。（2）后端：修复 OrderSync 将持仓标为已平仓时覆盖 `close_reason` 的问题——在 `ReducePositionQuantity` 中若该笔持仓已有 `close_reason`（如策略写入的 system:tp/system:sl），则保留不覆盖，仅空时才写 `sync`，使系统止损/止盈触发的平仓能正确显示为「系统」+「触发止盈/止损」。（3）新增 `docs/平仓类型显示说明.md`。
- **涉及**：`store/position.go`、`web/src/components/PositionHistory.tsx`、`docs/平仓类型显示说明.md`（新建）
