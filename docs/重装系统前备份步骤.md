# 重装系统前备份步骤（Cursor + Docker）

适用于 Windows，重装前按顺序执行即可。

---

## 一、准备工作

1. 备份根目录已定为：**`E:\备份`**（请确保 E 盘有足够空间）。
2. 在 `E:\备份` 下新建三个子文件夹：`Cursor`、`Docker`、`Projects`。  
   在 PowerShell 中执行以下命令可一次性创建：
   ```powershell
   New-Item -ItemType Directory -Force -Path "E:\备份\Cursor", "E:\备份\Docker", "E:\备份\Projects"
   ```

---

## 二、Cursor 备份

### 步骤 1：关闭 Cursor

完全退出 Cursor（包括托盘图标），避免文件被占用。

### 步骤 2：复制 Cursor 配置与数据

在资源管理器地址栏输入下面路径并回车，然后复制整个文件夹到 `E:\备份\Cursor\`：

| 序号 | 源路径（复制到地址栏） | 复制到 |
|------|------------------------|--------|
| ① | `%APPDATA%\Cursor` | `E:\备份\Cursor\Cursor_AppData` |
| ② | `%USERPROFILE%\.cursor` | `E:\备份\Cursor\cursor_user` |

**操作**：
- 按 `Win + R`，输入 `%APPDATA%` 回车，找到 `Cursor` 文件夹，整份复制到 `E:\备份\Cursor\Cursor_AppData`。
- 按 `Win + R`，输入 `%USERPROFILE%` 回车，若存在 `.cursor` 文件夹，整份复制到 `E:\备份\Cursor\cursor_user`。

### 步骤 3：（可选）导出 Cursor 设置 JSON

1. 打开 Cursor → `File` → `Preferences` → `Settings`。
2. 点击右上角 `{}`（Open Settings JSON）。
3. 全选复制内容，新建文本文件保存为 `E:\备份\Cursor\settings.json`。

### 步骤 4：（可选）记录已安装扩展

1. 在 Cursor 左侧点击扩展图标，查看已安装列表。
2. 在 `E:\备份\Cursor\` 下新建 `extensions_list.txt`，把重要扩展名称写进去，重装后按名字搜索安装。

---

## 三、Docker 备份

### 步骤 1：确认 Docker 正在运行

打开 PowerShell 或 CMD，执行：

```powershell
docker info
```

若无报错，说明 Docker 在运行，继续下一步。

### 步骤 2：列出当前镜像（确认要备份的镜像名）

```powershell
docker images
```

记下你要保留的镜像名和 TAG，例如：`nofx-nofx`、`nofx-nofx-frontend`，一般为 `latest`。

### 步骤 3：导出 Docker 镜像为文件

在 PowerShell 中执行：

```powershell
# 进入备份目录
cd E:\备份\Docker

# 导出后端镜像（名称按 docker images 结果修改）
docker save -o nofx-backend.tar nofx-nofx:latest

# 导出前端镜像
docker save -o nofx-frontend.tar nofx-nofx-frontend:latest
```

若有其他自定义镜像，按同样方式：`docker save -o 文件名.tar 镜像名:TAG`。

### 步骤 4：备份容器内的数据（重要：数据库、配置文件等）

若你的 nofx 项目把数据存在容器内（未挂载到本机目录），需要把数据拷出来：

```powershell
# 先看容器是否在运行及名称
docker ps -a

# 假设容器名为 nofx-trading，把容器内 /app 下的数据拷到本机（按需改容器名和路径）
docker cp nofx-trading:/app/data E:\备份\Docker\nofx-app-data
```

若项目用的是挂载卷（例如 `-v D:\nofx-data:/app/data`），则只需备份本机目录 `D:\nofx-data` 到 `E:\备份\Docker\` 即可，无需 `docker cp`。

### 步骤 5：备份 docker-compose 与项目配置

你的 nofx 代码已在 GitHub，重装后可直接 `git clone`。若本机有未提交的修改或本地配置文件，请一并复制：

- 复制整个项目文件夹到 `E:\备份\Projects\nofx`，例如：
  ```powershell
  xcopy "C:\Users\21588\nofx" "E:\备份\Projects\nofx" /E /I /H
  ```
- 或至少复制：`docker-compose.yml`、`.env`（若有）、各 `Dockerfile.*` 到 `E:\备份\Docker\`。

## 五、备份完成后的自检

1. 打开 `E:\备份`，确认存在：
   - `Cursor\Cursor_AppData`、`Cursor\cursor_user`（或你复制的对应内容）
   - `Docker\nofx-backend.tar`、`Docker\nofx-frontend.tar`
   - 若做了容器数据备份：`Docker\nofx-app-data` 或挂载卷的拷贝
   - （可选）`Projects\nofx` 或至少 `docker-compose.yml` 等
2. 若备份在 U 盘，可再复制一份到另一块盘或云盘，双份更安全。

---

## 六、重装系统后的恢复步骤（简要）

1. **安装软件**  
   安装 Cursor、Docker Desktop、Git。

2. **恢复 Cursor**  
   - 将 `E:\备份\Cursor\Cursor_AppData` 内所有内容复制到新系统的 `%APPDATA%\Cursor`。  
   - 将 `E:\备份\Cursor\cursor_user` 内所有内容复制到新系统的 `%USERPROFILE%\.cursor`。  
   - 若有 `settings.json`，在 Cursor 里打开 Settings JSON 粘贴回去。  
   - 按 `extensions_list.txt` 重新安装扩展。

3. **恢复代码与 Docker**  
   - 从 GitHub 拉取：`git clone https://github.com/LIULIBAO123/nofx.git`，或从 `E:\备份\Projects\nofx` 复制回来。  
   - 进入项目目录，加载镜像并启动：
     ```powershell
     cd nofx
     docker load -i E:\备份\Docker\nofx-backend.tar
     docker load -i E:\备份\Docker\nofx-frontend.tar
     docker compose up -d
     ```
   - 若备份过容器内数据，用挂载或 `docker cp` 把 `nofx-app-data` 拷回容器内对应路径后再启动服务。

4. **Git / GitHub**  
   重新登录 GitHub（浏览器或 Git 凭据管理器），测试 `git pull`、`git push`。

## 七、一页纸速查清单（打印或存手机）

```
□ 在 E:\备份 下建好 Cursor、Docker、Projects 三个文件夹
□ Cursor：复制 %APPDATA%\Cursor → E:\备份\Cursor\Cursor_AppData
□ Cursor：复制 %USERPROFILE%\.cursor → E:\备份\Cursor\cursor_user（若有）
□ Cursor：（可选）导出 settings.json 到 E:\备份\Cursor\，记扩展名到 extensions_list.txt
□ Docker：cd E:\备份\Docker，docker save 导出 nofx-nofx:latest、nofx-nofx-frontend:latest 为 .tar
□ Docker：备份容器内数据（docker cp 到 E:\备份\Docker\nofx-app-data）或挂载卷目录
□ Docker：备份 docker-compose.yml / 整个项目到 E:\备份\Projects\nofx
□ 自检：E:\备份 内 Cursor、Docker、Projects 文件完整、可打开
□ 第二份备份：可再拷一份到 U 盘或云盘
```

完成以上步骤后，即可进行系统重装；重装后按「六、重装系统后的恢复步骤」操作即可恢复 Cursor 与 Docker 环境。
