# 止盈策略：参数预设与说明

本文档给出**止盈相关参数的推荐预设值及依据**，并与**后端预设、前端默认、kernel 默认**对齐。

---

## 一、参数一览与推荐预设

### 1.1 全局与前置

| 参数 | 类型 | 推荐预设 | 说明与依据 |
|------|------|----------|------------|
| `enabled` | bool | true | 关闭则整块动态止盈不执行。 |
| `min_hold_minutes` | float64 | 10 | 与止损一致；未满不参与止盈，减少开仓即触发。前端/后端预设均为 10。 |
| `min_profit_percent_to_allow_tp` | *float64 | 0（不设） | 0=不限制；>0 时仅当当前浮盈（价格%）≥ 此值才允许触发任何止盈，避免极低盈利即平。预设不设。 |

### 1.2 分层止盈（Scaled）

| 参数 | 类型 | 推荐预设 | 说明与依据 |
|------|------|----------|------------|
| `scaled_enabled` | *bool | true | 有档位即参与检查；与「有档位即启用」逻辑一致。 |
| `scaled_levels` | [] | 5%/25%, 8%/25%, 12%/100% | 第一档 5% 起避免过早；第二档 8% 可勾选移动止损到盈亏平衡；第三档 12% 全平。 |

### 1.3 回撤止盈（Trailing TP）

| 参数 | 类型 | 推荐预设 | 说明与依据 |
|------|------|----------|------------|
| `trailing_tp_enabled` | *bool | false | 默认关；用户按需开启「盈利回调前止盈」。 |
| `trailing_tp_activate_profit_pct` | *float64 | 2 | kernel 默认 2%；至少 2% 盈利才考虑回撤触发。 |
| `trailing_tp_retrace_pct` | *float64 | 1.5 | 从峰值回撤 1.5% 满足固定回撤条件；与 ATR 取大防震荡。 |
| `trailing_tp_retrace_atr_mult` | *float64 | 0.5 | 回撤需 ≥ 0.5×ATR/价格；高波动时自动放宽。 |
| `trailing_tp_confirm_minutes` | float64 | 0 | 0=不确认；>0 需条件持续 N 分钟才执行，防毛刺。 |
| `trailing_tp_close_percent` | *float64 | 100 | 触发时全平；可改为 50 做部分平。 |
| `trailing_tp_activate_profit_pct_altcoin` | *float64 | 未设 | 未设或≤0 则非 BTC/ETH 也用主参数；可设 2.5 等略放宽山寨。 |
| `trailing_tp_retrace_pct_altcoin` | *float64 | 未设 | 同上，山寨可单独回撤%。 |

### 1.4 固定 / ATR / 阻力止盈

| 参数 | 类型 | 推荐预设 | 说明与依据 |
|------|------|----------|------------|
| `fixed_enabled` | *bool | false | 默认关；与分层/回撤/ATR 组合时按需开。 |
| `fixed_percent` | *float64 | 8 | 启用时达 8% 价格涨幅全平。 |
| `atr_enabled` | *bool | true（后端预设）/ false（前端默认） | 后端预设开以配合策略；前端新建时默认关，用户可开。 |
| `atr_multiplier_min` / `atr_multiplier_max` | *float64 | 2.5 / 4.0 | 倍数取中点；高波动时用 Max（见下）。 |
| `atr_use_max_in_high_volatility` | *bool | true | 高波动时用 Max 倍数，与止损侧宽容一致。 |
| `atr_high_volatility_threshold` | *float64 | 1.2 | atr ≥ atrLong×1.2 视为高波动，与止损一致。 |
| `atr_period_btc_eth` / `atr_period_altcoin` | *int | 20 / 14 | 主流币周期略长，山寨略短。 |
| `resistance_enabled` | *bool | false（前端）/ true（后端英预设） | 按策略版本可选。 |
| `resistance_buffer` | *float64 | 0.5 | 阻力/支撑缓冲%。 |

### 1.5 锁利（与止损协作）

| 参数 | 类型 | 推荐预设 | 说明与依据 |
|------|------|----------|------------|
| `lock_profit_percent` | *float64 | 2.5 | 达此盈利后由**止损侧**将回撤到入场价判为 breakeven 止损；止盈模块不直接读。**执行时与「保证金收益率%」比较**（非价格%），前后端预设 2.5。 |

---

## 二、预设落点

- **后端** `store.GetDefaultStrategyConfig`（中/英两套）：  
  `MinHoldMinutes: 10`、`MinProfitPercentToAllowTP: nil`、分层 5/8/12 与 25/25/100、`ATREnabled: true`、`ATRUseMaxInHighVolatility: true`、`ATRHighVolatilityThreshold: 1.2`、`LockProfitPercent: 2.5`；回撤与山寨回撤未设（用 kernel 默认或主参数）。
- **前端** `DynamicTakeProfitEditor` 的 `defaultConfig`：  
  与上表及后端对齐：`min_hold_minutes: 10`、`min_profit_percent_to_allow_tp: 0`、`atr_use_max_in_high_volatility: true`、`atr_high_volatility_threshold: 1.2`、`lock_profit_percent: 2.5`；未列出的可选项（如山寨回撤）不设=使用主参数。
- **kernel**：  
  `getFloat64Value` 在 ptr 为 nil 时使用文档中的默认（如回撤激活 2.0、回撤 1.5、ATR 倍数 2.0/4.0、高波动阈值 1.2）；`MinProfitPercentToAllowTP` 为 nil 或 ≤0 表示不限制。

---

## 三、小结

- 所有参数已按「合理分析后设为预设」在**后端预设**与**前端默认**中统一。
- 止盈与止损共用 `min_hold_minutes`、K 线周期与 ATR 数据源；锁利由止损侧执行，止盈仅用 `lock_profit_percent` 的数值预设，逻辑在止损。
- 新增项（最低盈利过滤、ATR 高波动用 Max、回撤山寨参数）均已在预设/默认中明确或注明「未设=不限制/用主参数」。
