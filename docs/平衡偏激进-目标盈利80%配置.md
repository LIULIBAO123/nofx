# 平衡偏激进 · 目标盈利 80% 配置

本文档给出**平衡偏激进**风格、以**盈利单占比约 80%** 为目标的止盈/止损建议：在保持一定容错（不因震荡被扫）的前提下，更积极锁利、更快砍掉逆势单。

---

## 一、目标与思路

| 目标 | 做法 |
|------|------|
| **盈利 80%** | 提高「以盈利出场」的订单占比：止盈稍积极、亏损单尽早砍。 |
| **平衡偏激进** | 止盈：分层略前移 + 回撤止盈开启；止损：逆势早退开启，其余不收紧以免震荡被扫。 |

- **止盈**：略降低档位/提前锁利（分层第三档 10%、回撤止盈开启），避免利润回吐。
- **止损**：不普遍收紧 ATR/追踪（保持 15m、2 周期确认），只**开启逆势早退**，让「从未浮盈且反向过大」的单子早点平仓，减少大亏单。

---

## 二、止损：建议启用与建议值

### 2.1 建议启用

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `enabled` | **true** | 动态止损总开关 |
| `trigger_logic` | **any** | 任一条件触发即执行 |
| `min_hold_minutes` | **10** | 未满不参与，避免刚开仓就被扫 |
| `confirm_cycles` | **2** | 连续 2 周期满足再执行 |
| `confirm_minutes` | **0** | 按周期数确认 |
| `klines_timeframe` | **15m** | 统一 K 线周期 |
| `support_resistance_use_ema20` | **false** | 仍用局部极值（按需可开） |
| **追踪止损** | **开启** | 曾浮盈后按档位与回撤%触发 |
| 追踪档位 | **2.5% 盈利 / 回撤 1.5%；6% 盈利 / 回撤 2.5%** | 与默认一致，不收紧 |
| **ATR 止损** | **开启** | 主止损逻辑 |
| ATR 倍数 | **1.5 / 2.5**（min/max） | 高波动用 max，不收紧 |
| ATR 周期 | BTC/ETH **20**，山寨 **14** | 与默认一致 |
| **高波动宽容** | **开启** | `atr_tolerance_enabled: true`，阈值 **1.2** |
| **逆势早退** | **开启** | 提高盈利占比、减少大亏单 |
| `adverse_exit_when_never_profit_atr` | **1.0** | 从未浮盈且反向 ≥ 1×ATR 即平（偏激进可 1.1～1.2） |
| `adverse_exit_when_never_profit_atr_altcoin` | **1.2**（可选） | 山寨略放宽，避免波动大被早砍；不设则与主倍数一致 |
| `adverse_exit_require_atr_spike` | **false** | 不要求 ATR 骤升，逆势早退更容易触发 |

### 2.2 建议关闭或保持

| 参数 | 建议 | 说明 |
|------|------|------|
| `initial_stop_percent` | **0** | 不用固定百分比兜底，保持动态/ATR/追踪为主；若需兜底可设 6～8 |
| `support_resistance_enabled` | **false** | 按需再开，减少复杂度 |

## 三、止盈：建议启用与建议值

### 3.1 建议启用

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `enabled` | **true** | 动态止盈总开关 |
| `min_hold_minutes` | **10** | 与止损一致 |
| `min_profit_percent_to_allow_tp` | **1.0** | 仅当当前浮盈（价格%）≥ 1% 才允许触发任何止盈，避免极低盈利即平 |
| **分层止盈** | **开启** | 有档位即检查 |
| 分层档位 | **5%/25%、8%/25%、10%/100%** | 第三档 10% 全平（比 12% 更易达成，偏激进锁利） |
| **回撤止盈（Trailing TP）** | **开启** | 盈利回调前止盈，提高盈利单占比 |
| `trailing_tp_activate_profit_pct` | **1.5** | 盈利 ≥ 1.5% 即考虑回撤触发（略激进） |
| `trailing_tp_retrace_pct` | **1.2** | 从峰值回撤 1.2% 触发（略紧） |
| `trailing_tp_retrace_atr_mult` | **0.5** | 与 ATR 取大，防震荡 |
| `trailing_tp_confirm_minutes` | **0** | 不按分钟确认，反应更快 |
| `trailing_tp_close_percent` | **100** | 触发时全平 |
| 山寨回撤（可选） | 激活 **2**%、回撤 **1.5**% | 山寨波动大，略放宽避免过早全平 |
| **ATR 止盈** | **开启** | 与分层/回撤组合 |
| ATR 倍数 | **2.5 / 4.0**（min/max） | 高波动用 max |
| **高波动用 Max** | **true** | 阈值 **1.2** |
| ATR 周期 | BTC/ETH **20**，山寨 **14** | 与默认一致 |
| **锁利（盈亏平衡）** | **2.5**（保证金%） | 达此后回撤到入场价由止损侧触发 breakeven |

### 3.2 建议关闭或保持

| 参数 | 建议 | 说明 |
|------|------|------|
| `fixed_enabled` | **false** | 分层+回撤+ATR 已够用；若开可设 10% 兜底 |
| `resistance_enabled` | **false** | 按需再开 |

## 五、与默认的差异小结

| 维度 | 默认（平衡） | 平衡偏激进 · 盈利 80% |
|------|--------------|------------------------|
| **止损** | 逆势早退关 | **逆势早退开，倍数 1.0（山寨可 1.2）** |
| **止盈** | 回撤止盈关；分层第三档 12% | **回撤止盈开**（激活 1.5%，回撤 1.2%）；**分层第三档 10%** |
| **止盈** | 最低盈利过滤 0 | **最低盈利过滤 1%**（避免极低盈利即平） |

按上表在「策略 → 动态止损 / 动态止盈」中修改并保存即可；运行一段时间后可结合实盘/回测结果微调逆势早退倍数（1.0～1.2）和回撤止盈激活/回撤%（1.2～1.5）。
