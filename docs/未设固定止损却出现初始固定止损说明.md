# 未设固定止损却出现「初始固定止损」说明

## 一、现象（以 SIREN 为例）

- 平仓类型显示：**触发动态止损：初始固定止损**。
- 用户未在界面上单独设置「固定止损」，却仍被该方式平仓。

## 二、原因

「初始固定止损」是否生效，由**当前策略**里的 **初始固定止损百分比（InitialStopPercent）** 决定，而不是由用户是否在某一笔上「手动勾选固定止损」决定。

- **策略来源**：若策略来自**后端默认预设**或**带默认参数的模板**，其中有一项为 **InitialStopPercent = 8**（即 8% 兜底），用于「极端行情硬止损」。
- **执行逻辑**：当 `InitialStopPercent > 0` 时，系统会按「入场价 ± 该百分比」算出一个固定止损价；价格触及该价位即触发 **initial** 类型止损，平仓原因记为 `system:sl:initial`，界面显示为「触发动态止损：初始固定止损」。
- **SIREN 这笔**：入场约 0.43189，若策略为 8%，则止损价 ≈ 0.43189×0.92 ≈ 0.3973；实际平仓价 0.39611，与 8% 固定止损一致，故被判定为「初始固定止损」触发。

因此：**您没有单独去「设定固定止损」，但使用的策略里默认带了 8% 的初始固定止损，所以会出现「初始固定止损」平仓。**

## 三、如何关闭「初始固定止损」

若希望**完全不使用**固定百分比止损，只依赖动态/ATR/追踪等：

1. 打开 **策略配置**（该交易员所绑定的策略）。
2. 进入 **动态止损** 配置。
3. 找到 **初始固定止损百分比**（或「Initial Stop %」「initial_stop_percent」）。
4. 将其设为 **0** 并保存。

设为 0 后，策略逻辑中不会再用「初始固定」这一档，仅会使用追踪止损、ATR 止损、支撑/阻力、逆势早退等，不会再出现「触发动态止损：初始固定止损」。

## 四、前后端已对齐说明（2026-03-04）

- **文档**（如《止损策略参数默认值与整体分析》）中建议：**initial_stop_percent 推荐默认 0**，与「无固定初始止损、仅用动态/ATR/追踪」一致。
- **前端**：动态止损编辑器文案为「已移除固定初始止损，仅使用动态/ATR/追踪止损」，且 defaultConfig 中 **initial_stop_percent: 0**；前端未展示该数字输入框，故用户看到的默认行为即为「无固定初始止损」。
- **后端**：已与前端对齐，**GetDefaultStrategyConfig**（中/英两套预设）中的 **InitialStopPercent 已改为 0**。新建或从默认模板加载的策略不再自带 8% 固定止损。
- 若日后需要「兜底」固定止损，可在策略配置中增加「初始固定止损 %」字段并设为大于 0 的数值（需前后端同时支持该配置项）。
