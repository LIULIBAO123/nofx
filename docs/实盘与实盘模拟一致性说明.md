# 实盘与实盘模拟功能一致性说明

本文档说明实盘与实盘模拟在核心逻辑上如何保持一致，以及新增功能时需注意的约定。

## 1. 设计原则

- **实盘模拟**使用 `PaperTrader` 适配器，资金与订单为虚拟，不向交易所发单。
- **除资金/订单真实性外**，持仓结构、动态止损止盈、分层止盈、展示字段等应与实盘一致，便于从模拟平滑切换到实盘。

## 2. 已统一的数据路径

### 2.1 持仓列表 `GetPositions`

| 层级 | 说明 |
|------|------|
| **API** | `handlePositions` 在交易员运行中时统一调用 `trader.GetPositions()`，不区分实盘/模拟。 |
| **AutoTrader** | `GetPositions()` 从 `at.trader.GetPositions()` 取原始持仓（交易所或 PaperTrader），再用同一套 `getPosStr`/`getPosFloat` 解析并计算衍生字段。 |
| **衍生字段** | 包括：`unrealized_pnl_pct`、**`price_change_pct`**、`distance_to_sl_pct`、`distance_to_tp_pct`、`trailing_enabled`/`trailing_tier_activated`、`scaled_tp_enabled`/`scaled_tp_level`/`scaled_tp_closed_pct`、止损/止盈价、ATR 等，实盘与模拟使用相同逻辑。 |

因此，**当前持仓**中的「价格变动」「分层止盈」「追踪止损」等展示在实盘与实盘模拟下一致。

### 2.2 动态止损/止盈检查 `checkDynamicStopLossTakeProfit`

- 统一调用 `at.trader.GetPositions()` 获取当前持仓（实盘=交易所，模拟=PaperTrader 内存）。
- 最小持仓时间、LockProfit、追踪止损、分层止盈、支撑阻力止损等判断与执行逻辑**不区分**实盘/模拟。
- 模拟仅在实际下单/撤单时为 no-op（PaperTrader 的 SetStopLoss/SetTakeProfit/Cancel* 为空实现），策略层的「是否触发、平多少仓」与实盘一致。

### 2.3 账户信息 `GetAccountInfo`

- 运行中时统一走 `trader.GetAccountInfo()`（实盘=交易所余额，模拟=PaperTrader 虚拟余额）。
- 返回结构一致，前端无需区分。

### 2.4 Paper 持仓格式与解析

`PaperTrader.GetPositions()` 返回的 map 使用与交易所兼容的 fallback 键名，便于 AutoTrader 统一解析：

| 字段 | Paper 键名 | 交易所常见键名 | 用途 |
|------|------------|----------------|------|
| 方向 | `position_side` | `side` | getPosStr(..., "position_side") |
| 数量 | `position_amt` | `positionAmt` | getPosFloat(..., "position_amt") |
| 入场价 | `entry_price` | `entryPrice` | 价格变动%、分层止盈判断 |
| 标记价 | `mark_price` | `markPrice` | 同上 |
| 未实现盈亏 | `unrealized_pnl` | `unRealizedProfit` | 当前盈亏%、保证金收益率 |
| 杠杆 | `leverage` | `leverage` | 保证金计算 |
| 入场时间 | `update_time` | `updateTime`/`entry_time` | 最小持仓、SL/TP 检查 |

缺少的字段（如 `liquidation_price`）在 AutoTrader 中解析为 0，不影响统一展示与策略逻辑。

## 3. 仅「交易员未运行」时的差异（回退逻辑）

当 `GetTrader(traderID)` 失败（交易员未启动）时：

| 接口 | 实盘 | 实盘模拟 |
|------|------|----------|
| 持仓 | 404 Trader not found | 200 + 空数组 `[]` |
| 状态 | 404 | 200 + DB 静态信息（名称、初始资金等） |
| 账户 | 404 | 需单独实现回退时再定 |
| 决策记录/统计等 | 404 | 200 + 从 DB 拉取 |

目的是让模拟看板在交易员暂停时仍可访问、不报 404，而不是改变「运行中」时的数据结构。

## 4. 新增功能时的约定

- **持仓相关字段或计算**（如新增一种止盈方式、新展示项）：在 **AutoTrader.GetPositions()** 或 **checkDynamicStopLossTakeProfit** 中实现，**不要**根据 `at.config.IsSimulation` 分支给出不同结构或不同计算方式。
- **PaperTrader** 只需保证返回的原始 map 包含 AutoTrader 所需键（或兼容 fallback）；若新字段需从「交易所独有」数据来，Paper 可返回 0 或空，由上层统一处理。
- **API 层**：在交易员运行中时，仅调用 trader 的同一套接口，不按 `is_simulation` 返回不同结构。

按上述约定，实盘与实盘模拟在展示与策略行为上可保持一致。
