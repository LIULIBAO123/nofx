## 🚀 快速开始

### 1. 导入策略

在 nofx 系统中导入策略文件：
```
strategies/optimized_strategy_v2.json
```

### 2. 核心参数说明

#### 风险控制
```json
{
  "max_positions": 3,              // 最大持仓数
  "max_margin_usage": 0.90,        // 最大保证金使用率90%
  "min_position_size_usdt": 12,    // 最小仓位12 USDT
  "btc_eth_max_leverage": 10,      // BTC/ETH最大10倍杠杆
  "altcoins_max_leverage": 5       // 山寨币最大5倍杠杆
}
```

#### 仓位管理
```json
{
  "enable_pyramiding": true,       // 启用金字塔加仓
  "max_pyramid_levels": 2,         // 最多加仓2次
  "pyramid_size_ratio": 0.5,       // 每次加仓比例递减50%
  "min_profit_to_add": 1.0,        // 盈利>1%才能加仓
  
  "enable_scaled_exit": true,      // 启用分批止盈
  "scaled_exit_levels": [
    {"profit": 3.0, "exit": 33},   // 盈利3%平仓33%
    {"profit": 5.0, "exit": 50},   // 盈利5%再平仓50%
    {"profit": 8.0, "exit": 100}   // 盈利8%全部平仓
  ],
  
  "min_hold_time": "30m",          // 最小持仓30分钟
  "max_hold_time": "4h"            // 最大持仓4小时
}
```

#### 回撤控制
```json
{
  "max_drawdown_limit": 0.20,      // 最大回撤限制20%
  "drawdown_levels": [
    {"threshold": 0.10, "action": "reduce_size", "multiplier": 0.5},  // 10%减仓50%
    {"threshold": 0.15, "action": "stop_new_trades"},                 // 15%停止开仓
    {"threshold": 0.20, "action": "close_all"}                        // 20%全部平仓
  ],
  "recovery_threshold": 0.05,      // 回撤降至5%以下退出恢复模式
  "recovery_position_size": 0.5    // 恢复期间仓位限制50%
}
```

## 📊 止损止盈配置

### 止损模式（4种）

#### 1. 固定止损
```json
{
  "mode": "fixed",
  "percentage": 3.0,
  "description": "固定3%止损，适合稳定市场"
}
```

#### 2. 追踪止损
```json
{
  "mode": "trailing",
  "activation_profit": 2.0,      // 盈利2%后启动
  "trailing_distance": 1.5,      // 追踪距离1.5%
  "description": "保护利润，让盈利奔跑"
}
```

#### 3. ATR动态止损（推荐）
```json
{
  "mode": "atr",
  "multiplier": 2.0,             // 2倍ATR
  "min_percentage": 2.0,         // 最小2%
  "max_percentage": 5.0,         // 最大5%
  "description": "根据波动率自动调整"
}
```

#### 4. 支撑/阻力位止损
```json
{
  "mode": "support_resistance",
  "buffer_percentage": 0.5,      // 缓冲0.5%
  "lookback_periods": 20,        // 回溯20根K线
  "description": "基于技术分析"
}
```

## 🎯 AI决策逻辑

### 多时间框架分析

```
4h周期 (大趋势)
    ↓
1h周期 (趋势确认)
    ↓
15m周期 (精确入场)
```

#### 开仓条件（必须三周期共振）
- **做多**: 4h上升 + 1h上升 + 15m买入信号
- **做空**: 4h下降 + 1h下降 + 15m卖出信号
- **观望**: 周期不一致时保持观望

### 市场状态识别

#### 趋势判断
1. **强上升趋势**: 价格>EMA20>EMA50，MACD>0且上升，成交量放大
2. **上升趋势**: 价格>EMA20，MACD>0
3. **横盘震荡**: 价格在EMA20附近波动，MACD接近0
4. **下降趋势**: 价格<EMA20，MACD<0
5. **强下降趋势**: 价格<EMA20<EMA50，MACD<0且下降，成交量放大

#### 波动率判断
- **极端波动**: ATR > 平均ATR的2倍
- **高波动**: ATR > 平均ATR的1.5倍
- **正常波动**: ATR在平均ATR的0.8-1.5倍之间
- **低波动**: ATR < 平均ATR的0.8倍

#### 成交量判断
- **成交激增**: 当前成交量 > 平均成交量的2倍
- **高成交**: 当前成交量 > 平均成交量的1.5倍
- **正常成交**: 当前成交量在平均成交量的0.8-1.5倍之间
- **低成交**: 当前成交量 < 平均成交量的0.8倍

### OI（持仓量）解读

| OI变化 | 价格变化 | 解读 | 操作建议 |
|--------|----------|------|----------|
| 增加 | 上涨 | 强多头趋势（新多单开仓） | 做多 ✅ |
| 增加 | 下跌 | 强空头趋势（新空单开仓） | 做空 ✅ |
| 减少 | 上涨 | 空头平仓（可能反转） | 谨慎做多 ⚠️ |
| 减少 | 下跌 | 多头平仓（可能反转） | 谨慎做空 ⚠️ |

### 资金费率解读

| 资金费率 | 市场情绪 | 操作建议 |
|----------|----------|----------|
| > 0.1% | 极度看多 | 警惕多头过热 ⚠️ |
| 0.01% ~ 0.1% | 正常看多 | 可以做多 ✅ |
| -0.01% ~ 0.01% | 中性 | 观望 |
| -0.1% ~ -0.01% | 正常看空 | 可以做空 ✅ |
| < -0.1% | 极度看空 | 警惕空头过热 ⚠️ |

### 资金流分析

| 机构资金 | 散户资金 | 解读 | 操作建议 |
|----------|----------|------|----------|
| 流入 | 流出 | 强烈看涨信号 | 做多 ✅✅ |
| 流出 | 流入 | 警惕信号（可能是顶部） | 观望/做空 ⚠️ |
| 流入 | 流入 | 趋势确认（上涨） | 做多 ✅ |
| 流出 | 流出 | 趋势确认（下跌） | 做空 ✅ |

## 📈 交易场景示例

### 场景1: 强势突破做多 ✅

**市场状态**:
- 4h: 强上升趋势，价格突破前高
- 1h: 上升趋势，MACD金叉
- 15m: 回调至EMA20获得支撑
- OI: 快速增加+12%
- 资金流: 机构流入+5M，散户流出-2M
- 资金费率: 0.05%（正常看多）

**AI决策**: 做多，信心度85
**理由**: 三周期共振，OI增加确认新多单开仓，机构资金流入，回调提供低风险入场点

**仓位管理**:
- 初始仓位: 1x权益
- 盈利1%后可加仓0.5x
- 盈利3%平仓33%
- 盈利5%再平仓50%
- 盈利8%全部平仓

---

### 场景2: 假突破识别 ⚠️

**市场状态**:
- 4h: 横盘震荡
- 1h: 价格突破阻力位
- 15m: RSI超买(78)
- OI: 减少-5%
- 资金流: 机构流出-3M，散户流入+4M
- 成交量: 低于平均

**AI决策**: 观望
**理由**: OI减少说明是空头平仓而非新多单，散户接盘，成交量不足，疑似假突破

---

### 场景3: 趋势反转做空 ✅

**市场状态**:
- 4h: 下降趋势，价格跌破EMA50
- 1h: 反弹至EMA20遇阻
- 15m: MACD死叉，RSI从超买回落
- OI: 增加+8%
- 资金流: 机构流出-6M
- 资金费率: -0.08%（看空）

**AI决策**: 做空，信心度80
**理由**: 趋势反转确认，反弹提供高位做空机会，OI增加确认新空单开仓

---

### 场景4: 超跌反弹做多 ⚠️

**市场状态**:
- 4h: 下降趋势但RSI超卖(25)
- 1h: 出现底部背离
- 15m: 价格突破下降趋势线
- OI: 大幅减少-15%
- 资金流: 机构开始流入+2M
- 成交量: 放大

**AI决策**: 做多（短线），信心度70
**理由**: 超卖反弹，OI大幅减少说明空头平仓，机构开始抄底，但大趋势仍下降，只做短线

**注意**: 持仓时间不超过2小时，快进快出

---

### 场景5: 高位震荡观望 ⚠️

**市场状态**:
- 4h: 上升趋势但出现顶背离
- 1h: 横盘震荡

- OI: 持平
- 资金流: 机构流出-4M，散户流入+5M
- 资金费率: 0.15%（极度看多）

**AI决策**: 观望
**理由**: 顶背离警示，散户接盘，资金费率过高，多头过热，等待更明确信号

## 📝 注意事项

### ⚠️ 重要提醒

1. **回测不等于实盘**: 实盘效果可能与回测有差异
2. **市场环境变化**: 根据市场情况及时调整参数

5. **资金管理**: 不要投入超过承受能力的资金

### ✅ 最佳实践

1. **小资金测试**: 先用小资金测试1-2周
2. **逐步增加**: 确认稳定后再增加资金
3. **定期复盘**: 每周复盘交易记录
4. **参数优化**: 根据实际效果调整参数
5. **风险分散**: 不要把所有资金放在一个策略上

## 🆘 故障排查

### 问题1: AI决策信心度过低
**原因**: 市场信号不明确
**解决**: 降低 `min_confidence` 或等待更明确信号

### 问题2: 频繁止损
**原因**: 止损设置过紧
**解决**: 调整止损模式为ATR动态止损

### 问题3: 回撤过大
**原因**: 仓位过重或未及时止损
**解决**: 降低杠杆，启用回撤控制

### 问题4: 盈利回吐
**原因**: 未及时止盈
**解决**: 启用分批止盈或追踪止损
